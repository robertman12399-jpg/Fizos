# ФизМат RPG — PWA (устанавливаемое веб-приложение)

Эта папка превращает `Fizika.html` в приложение, которое:
- открывается по обычной ссылке в браузере (как сейчас);
- предлагает **«Установить»** / «Добавить на главный экран» — иконка появляется на рабочем столе телефона, открывается без адресной строки, как настоящее приложение;
- после первого открытия **работает без интернета** (весь код уже внутри одного файла, поэтому кэшировать особо и нечего — просто сам файл).

Никакой Java, никакого магазина приложений, никакого сервера с базой данных — это тот же самый код игры, просто с несколькими служебными файлами рядом.

## Что здесь лежит

| Файл | Зачем |
|---|---|
| `index.html` | Собранная игра (то же, что `Fizika.html`, просто переименован — хостинги по умолчанию открывают `index.html`) |
| `manifest.json` | Имя, иконка и цвет приложения — то, что браузер использует при установке |
| `sw.js` | Service Worker — кэширует игру для работы офлайн |
| `icon-*.png` | Иконки разных размеров (обычные + maskable для Android, отдельная для iOS) |

**Важно:** все файлы должны лежать **в одной папке рядом друг с другом** на хостинге — не переименовывайте и не перекладывайте их отдельно.

## Как опубликовать — вариант 1: GitHub Pages (бесплатно, без ограничений)

1. Зайдите на [github.com](https://github.com), создайте новый репозиторий (например, `fizmat-rpg`) — можно публичный.
2. Загрузите в него **все файлы из этой папки** (перетащить через веб-интерфейс GitHub — кнопка «Add file → Upload files», можно все сразу).
3. Зайдите в **Settings → Pages** репозитория.
4. В разделе «Source» выберите ветку `main` и папку `/ (root)`, нажмите Save.
5. Через 1-2 минуты GitHub даст ссылку вида `https://ваш-логин.github.io/fizmat-rpg/` — это и есть ссылка для учеников.

## Как опубликовать — вариант 2: Netlify (тоже бесплатно, чуть проще)

1. Зайдите на [netlify.com](https://netlify.com), зарегистрируйтесь (можно через Google-аккаунт).
2. На главной странице после входа — просто **перетащите всю эту папку** в область «Drag and drop your site output folder here».
3. Netlify сама всё разложит и через несколько секунд даст ссылку вида `https://случайное-имя.netlify.app/`.
4. При желании в настройках сайта можно поменять `случайное-имя` на что-то своё (бесплатно).

Оба варианта дают HTTPS автоматически — это обязательное условие для работы Service Worker (офлайн-режим и установка не заработают на обычном `http://`).

## Как ученик устанавливает приложение

1. Открывает ссылку в браузере на телефоне (Chrome на Android, Safari на iPhone).
2. **Android (Chrome):** снизу или сверху появится баннер «Добавить ФизМат RPG на главный экран» — либо через меню (три точки) → «Установить приложение».
3. **iPhone (Safari):** кнопка «Поделиться» (квадрат со стрелкой вверх) → «На экран “Домой”».
4. Дальше иконка на рабочем столе открывает игру в полноэкранном режиме, без адресной строки браузера.

## Как обновлять игру в будущем

Когда я пришлю вам новую версию `Fizika.html` (с исправлениями или новым контентом):

1. Переименуйте новый файл в `index.html`.
2. **Откройте `sw.js` и смените строку** `CACHE_VERSION = "fizmat-rpg-v1"` на `"fizmat-rpg-v2"` (просто увеличьте цифру) — это обязательный шаг, без него у учеников, которые уже установили приложение, будет висеть старая закэшированная версия и они не увидят изменений.
3. Замените `index.html` и `sw.js` на хостинге (загрузите поверх старых).
4. Ученики получат новую версию автоматически при следующем открытии с интернетом — им не нужно ничего переустанавливать.

## Если что-то пошло не так

- **Не появляется кнопка «Установить»** — проверьте, что зашли именно по `https://`, а не `http://`, и что `manifest.json` лежит рядом с `index.html` в той же папке.
- **Офлайн не работает** — откройте игру онлайн хотя бы один раз до того, как отключить интернет (Service Worker должен успеть закэшировать файл при первом посещении).
- **Обновление не приходит ученикам** — проверьте, что вы поменяли `CACHE_VERSION` в `sw.js` (см. раздел выше).
