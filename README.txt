ФизМат RPG - автоматические обновления без потери локальных данных
Релиз 2026.11.18.1

Публикация в GitHub Pages
1. Распакуйте архив. Загрузите ВСЕ файлы из архива в корень действующего репозитория GitHub Pages.
2. Не меняйте адрес сайта (https://<username>.github.io/<repo>/) и НЕ меняйте имя репозитория:
   данные localStorage связаны с адресом (origin) и профилем браузера.
3. Не удаляйте сохранения и не просите учеников чистить "данные сайта".
4. Если ученики открывают сайт, изменение подхватится при следующем открытии.
   Если приложение установлено PWA и старая версия уже открыта, дообновление может
   потребовать повторного открытия после первого перехода со старого Service Worker.
5. В дальнейшем при каждом релизе изменяйте CACHE_NAME в sw.js и публикуйте новый
   index.html + sw.js. При обнаружении обновления ученику показывается кнопка "Обновить".

Что сохраняется
- fizmatrpg.save.v1: герой, задания, игровая экономика, домашние задания;
- fizmatrpg.journal.v1: события и ошибки;
- fizmat_homelab_v1: домашняя лаборатория;
- другие ключи приложения в localStorage.
Новый Service Worker обновляет ТОЛЬКО кеш ресурсов (Cache Storage).
Не содержит localStorage.clear(), IndexedDB.deleteDatabase() или аналогичных операций.
Обновление страницы происходит ТОЛЬКО при нажатии "Обновить".

Резервная копия: в приложении раздел сохранений -> "Экспорт" (файл .json).
Сделайте копию перед первой публикацией обновленной сборки.
Если пользователь скачал самостоятельный HTML-файл (file://), автоматические обновления невозможны.
Если изменён домен/адрес GitHub Pages, локальные данные автоматически НЕ переедут.

Файлы:
index.html - упакованный/обфусцированный HTML
sw.js - service worker для офлайн-запуска и обновления
manifest.json - описание PWA
icon-*.png - значки приложения
